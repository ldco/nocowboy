# Spec: UI Локализация

> Generated by architect. Code agent implements against this spec.

## Feature
- **ID:** ui-localization
- **Description:** Русские метки в TUI + переключатель языка
- **Acceptance criteria:** docs/roadmap.json

## Technical context
- i18n система: `packages/opencode/src/nocowboy/ui/i18n.ts` (35 ключей)
- TUI: SolidJS + OpenTUI, компоненты в `src/cli/cmd/tui/component/`
- Конфиг: `lang` поле в nocowboy.json

## Files to change
| File | Change |
|------|--------|
| `src/cli/cmd/tui/component/sidebar.tsx` | Локализовать метки через I18nService |
| `src/cli/cmd/tui/component/dialog/` | Локализовать кнопки/заголовки диалогов |
| `src/cli/cmd/tui/component/status-bar.tsx` | Локализовать статус агента |

## Implementation steps
1. Внедрить I18nService в Component Tree (Context.Provider)
2. Заменить хардкодные строки на `t(key)` в sidebar
3. Заменить хардкодные строки в диалогах
4. Добавить переключатель языка в Settings (dropdown ru/en)
5. При смене lang → перезагрузить I18nService

## Edge cases
- Нет перевода для ключа → fallback на английский
- Переключение языка во время активной сессии → не ломает чат
