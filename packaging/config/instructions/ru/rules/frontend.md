# Правила разработки фронтенда

- Используй библиотеку компонентов проекта — не строй кастомные компоненты с нуля
- Каждый компонент должен обрабатывать состояния: загрузки, пустого, ошибки и граничные случаи
- Используй адаптивный дизайн с консистентными брейкпоинтами (mobile, tablet, desktop)
- Все интерактивные элементы должны быть доступны с клавиатуры
- Добавляй aria-метки для всех иконок-кнопок и полей ввода
- Никогда не используй inline-стили — используй CSS modules, Tailwind или систему стилизации проекта
- Используй семантические HTML-элементы (button, nav, header, main, section)
- Лениво загружай контент ниже сгиба и изображения
- Мемоизируй дорогие вычисления через computed/useMemo
- Избегай prop drilling — используй context/composables для общего состояния
- Тестируй всё пользовательское поведение через компонентные тесты
