# Правила доступа к базе данных

- Никогда не используй raw SQL — используй ORM (Drizzle, Prisma, TypeORM, SQLAlchemy)
- Всегда валидируй входные данные перед запросами к БД
- Используй параметризованные запросы для любого raw SQL (если неизбежно)
- Индексируй все колонки, используемые в WHERE, JOIN и ORDER BY
- Добавляй unique constraints для бизнес-уникальных полей
- Используй миграции для изменений схемы, никогда — ручной ALTER TABLE
- Миграции должны быть обратимыми (up и down)
- Пагинируй все list-запросы для предотвращения переполнения памяти
- Используй транзакции для multi-step операций записи
- Никогда не делай `select *` — всегда указывай колонки
- Добавляй внешние ключи на уровне БД для ссылочной целостности
