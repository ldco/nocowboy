# Структурированный вывод

## Когда использовать

Когда результат нужен в формате, пригодном для парсинга: JSON, таблицы, отчёты.

## Правила

- `nocowboy --json` или `/json` — только JSON, никакого пояснительного текста
- Для таблиц — markdown таблицы с выравниванием
- Для списков — маркированные списки с понятными заголовками

## Формат JSON

```json
{
  "ok": true,
  "data": {},
  "error": null
}
```

При ошибке:

```json
{
  "ok": false,
  "data": null,
  "error": {
    "code": "ERROR_CODE",
    "message": "Понятное описание"
  }
}
```
