# /share — Share Session

Generate a shareable URL for the current conversation.

## Steps

1. **Check session** — verify there's an active session
2. **Share** — the TUI has a built-in share button that generates a URL
3. **Copy** — the URL is copied to your clipboard
4. **Send** — share the URL with anyone

The shared session is read-only. Your session continues normally.

## Privacy

- Shared sessions expire after 7 days
- You can see what you share before confirming
- No personal data is shared (session ID only)
