## 152-ФЗ "О персональных данных" — Ключевые статьи

### Ст. 3 — Определения
- Персональные данные — любая информация, относящаяся к физическому лицу
- Обработка — любое действие с ПДн (сбор, хранение, передача, удаление)
- Оператор — кто организует обработку

### Ст. 6 — Условия обработки
Обработка законна когда:
1. Есть согласие субъекта (Ст. 9)
2. Нужно по договору
3. Для исполнения закона
4. Для защиты жизни/здоровья
5. Законные интересы оператора
6. Статистика/наука (с обезличиванием)

### Ст. 9 — Согласие (CRITICAL)
- Должно быть **конкретным, информированным, сознательным**
- Любая форма: письменная, электронная, конклюдентные действия
- Оператор обязан доказать наличие согласия
- Субъект может **отозвать** в любой момент
- Обработка прекращается в течение 30 дней после отзыва
- **Биометрия** — только письменное согласие

### Ст. 10 — Специальные категории
Раса, национальность, политика, религия, здоровье, интимная жизнь, судимость
- Запрещены кроме исключений (письменное согласие, трудовое право, и т.д.)

### Ст. 12 — Трансграничная передача
- Страны из «белого списка» РКН — без ограничений
- Не-белый список — только с **письменного согласия**
- С 01.03.2023 — уведомление РКН о намерении передавать данные за рубеж

### Ст. 14 — Права субъекта
Субъект имеет право:
- Получить информацию об обработке
- Требовать блокирования, уничтожения, уточнения
- Ответ в течение **10 рабочих дней**

### Ст. 15 — Уточнение, блокирование, уничтожение
- Неполные, устаревшие, незаконно полученные данные → блокируются
- Уведомить третьих лиц, получивших эти данные

### Ст. 18 — Обязанности оператора
- Предоставить информацию по запросу (Ст. 14)
- Принять меры по уточнению неполных данных
- Удовлетворить требования субъекта
- Уведомить РКН о начале обработки (Ст. 22)

### Ст. 21 — Локализация данных
**Критично:** При сборе ПДн (в т.ч. через интернет) оператор обязан обеспечить **запись, систематизацию, накопление, хранение, уточнение, извлечение** ПДн граждан РФ с использованием **баз данных, находящихся на территории РФ**.

→ База данных должна быть в РФ. После этого возможна трансграничная передача.

### Ст. 22 — Уведомление РКН
До начала обработки оператор уведомляет РКН:
- Наименование, адрес
- Цели обработки
- Категории ПДн
- Категории субъектов
- Правовое основание
- Описание мер защиты
- Ответственное лицо
- Дата начала обработки
- Информация о трансграничной передаче
- Подтверждение локализации в РФ

### Ст. 22.1 — Ответственный за обработку ПДн
- Назначается оператором
- Внутренний контроль за соблюдением 152-ФЗ
- Обработка обращений субъектов

### Ст. 24 — Ответственность (штрафы по КоАП 13.11)
| Нарушение | Штраф для юрлица |
|-----------|-----------------|
| Обработка без согласия | до 150K ₽ |
| Нет политики обработки | до 30K ₽ |
| Непредоставление информации | до 45K ₽ |
| Неудаление по требованию | до 90K ₽ |
| Нарушение локализации (впервые) | до **6M ₽** |
| Нарушение локализации (повторно) | до **18M ₽** |

## Cookie-файлы в РФ
- Нет отдельного «cookie law» как в ЕС
- Требуется: информирование + согласие (Ст. 9)
- Технические cookie — могут без согласия
- Аналитика/маркетинг — обязательно согласие
- Баннер с accept/decline, ссылка на политику

## Формат согласия на обработку ПДн (шаблон)
```
Я даю согласие на обработку моих персональных данных,
указанных в данной форме, в соответствии с ФЗ от 27.07.2006 № 152-ФЗ
«О персональных данных» и Политикой обработки ПДн [ссылка].

Цель обработки: [указать].
Состав данных: [перечислить].
Срок обработки: [указать].
Согласие может быть отозвано в любой момент.
```
