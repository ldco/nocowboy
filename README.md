# NoCowboy

![NoCowboy](logo.svg)

**ИИ под твоим контролем.** Терминальный AI-агент для разработки. Создан для российского рынка — без привязки к западным сервисам, без санкционных ограничений.

---

## Почему NoCowboy

1.7 миллиона российских разработчиков испытывают проблемы с доступом к западным AI-инструментам. Формально многие «доступны», но на практике пользоваться ими неудобно, дорого и ненадёжно.

### Западные AI-инструменты: доступ есть, но какой ценой

**Оплата.** Visa и Mastercard ушли из РФ, SWIFT-переводы заблокированы. Российские карты не принимаются ни одним западным AI-сервисом. Оплата через посредников стоит +20-40%, без гарантий — аккаунт могут забанить в любой момент, деньги не возвращаются.

**Цена.** Claude Sonnet 5: $2 вход + $10 выход за миллион токенов. Месяц активной разработки — $200-500. Для сравнения, DeepSeek V4 Flash: $0.14 вход + $0.28 выход — **в 7-18 раз дешевле**. Но цена API — не главное. DeepSeek можно прикрутить к любому инструменту.

Главное — **качество харнеса**: 5 агентов с перекрёстным ревью, скомпилированный бинарник без Node.js, русский интерфейс, автономная работа без внешних API.

### Почему NoCowboy лучше других харнесов

| Харнес | Модель | NoCowboy |
|--------|--------|----------|
| **Запуск** | Cursor: Electron 300MB → старт 5 сек. Aider: Python + pip install. Claude Code: Node.js + npm install -g | **Один бинарник 227MB — скопировал и работает.** Без Node.js, Python, Docker |
| **Агенты** | Claude Code: 1 агент + sub-agents. Cursor: Agent vs Chat. Copilot: Plan/Agent. Aider: 4 режима одной моделью | **5 агентов с перекрёстным ревью.** overseer проверяет code **другой моделью** (Kimi ревьюит DeepSeek) — model-blindness пробита |
| **Контекст** | Все теряют контекст между сессиями | **FTS5-память** сохраняет паттерны, баги, решения — загружаются в каждую новую сессию |
| **Качество кода** | Никто не проверяет AI-выход автоматически | **Constitution MCP** — AST-level правила (нет @ts-ignore, нет catch{}, нет any). Pre-commit блок |
| **MCP-серверы** | Ручной запуск каждого сервера | **8 серверов стартуют автоматически** — Constitution, Puppeteer, Git, SQLite, +4 |
| **Русский язык** | Все промпты и интерфейс на английском | **Русские промпты, русские инструкции, русский TUI.** Встроенный справочник IT-права РФ |
| **Автономность** | Большинству нужен интернет и API-ключ | **Полный офлайн.** Локальные модели через Ollama/GigaChat/YandexGPT. Никаких внешних API |
| **Независимость** | Зависят от вендора | **Self-hosting.** NoCowboy разрабатывает сам себя. 0 внешних зависимостей |

### Агенты — перекрёстный ревью

5 агентов работают вместе. code пишет, overseer проверяет **другой моделью**:

| Агент | Что делает | Модель |
|-------|-----------|--------|
| **code** | Пишет код | Flash |
| **architect** | Архитектура, планы, ADR | Pro |
| **debug** | Отладка | Flash |
| **overseer** | Ревью + оркестрация. Kimi проверяет код, написанный DeepSeek — model-blindness не пройдёт | **Kimi K2 / Pro** |
| **nocowboy** | Автоматизация: браузер, файлы, система | Flash |

## Быстрый старт

```bash
bun install --cwd packages/opencode build --single
cp packages/opencode/dist/nocowboy-tui-linux-x64/bin/nocowboy ~/.local/bin/nocowboy

nocowboy init          # мастер настройки
nocowboy mcp start     # MCP-серверы
nocowboy               # старт TUI
```

Конфиг: `~/.config/nocowboy/nocowboy.jsonc`
