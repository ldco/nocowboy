# NoCowboy

![NoCowboy](logo.svg)

**ИИ под твоим контролем.** Терминальный AI-агент для разработки. Создан для российского рынка — без привязки к западным сервисам, без санкционных ограничений, без вендор-лока.

---

## Почему NoCowboy

1.7 миллиона российских разработчиков испытывают проблемы с доступом к западным AI-инструментам. Формально многие сервисы «доступны» — но на практике пользоваться ими неудобно, дорого и ненадёжно.

### Западные AI-инструменты: доступ есть, но какой ценой

**Claude API (Anthropic).** Формально не заблокирован в РФ. Но:

- Оплата только картами США/ЕС. Российские карты не принимаются. Visa и Mastercard ушли из РФ — прямой оплаты нет
- Даже если оплатить через посредника или крипто-шлюз — аккаунт может быть забанен при обнаружении российского IP или платёжного следа. Деньги не возвращаются
- Подписка Claude Pro ($20/мес) даёт жёсткие квоты — 45 сообщений за 5 часов. После исчерпания — ожидание или переход на медленный режим
- **Цена API** (на 1 млн токенов): Claude Haiku 4.5 — $1 вход / $5 выход. Claude Sonnet 5 — $2 вход / $10 выход. За месяц активной разработки — счёт $200-500

**GitHub Copilot.** Формально работает в РФ. Но:

- Оплата только западными картами (Visa/Mastercard). Российские банки отключены от SWIFT
- Подписка $10/мес — но купить её практически невозможно без карты иностранного банка
- Корпоративные лицензии требуют верификации организации — для российских юрлиц недоступно

**OpenAI (ChatGPT, Codex).**

- API оплата: только карты США/ЕС. Российские карты отклоняются
- Подписка ChatGPT Plus ($20/мес): только через иностранную карту
- Аккаунты с российских IP могут быть ограничены или забанены без предупреждения
- Codex CLI: публичный early access, но API-ключ требует верификации платёжного метода

**Cursor.** Работает через VPN. Но:

- Подписка $20/мес требует иностранную карту
- Прокси-оплата через посредников добавляет 20-40% комиссии
- Риск бана при обнаружении российского IP

### А что взамен? DeepSeek и китайские модели

**DeepSeek API.** Полностью доступен из РФ: $0.14 вход / $0.28 выход за миллион токенов — **в 7 раз дешевле** Claude Haiku по входу и **в 18 раз дешевле** по выходу.

| Модель | Вход (1M токенов) | Выход (1M токенов) |
|--------|-------------------|---------------------|
| Claude Sonnet 5 | $2 | $10 |
| Claude Haiku 4.5 | $1 | $5 |
| **DeepSeek V4 Flash** | **$0.14** | **$0.28** |
| **DeepSeek V4 Pro** | **$0.44** | **$0.87** |

**В 5-18 раз дешевле.** При месяце активной разработки: DeepSeek — $20-50, Claude — $200-500.

### Что NoCowboy решает

| Боль | Решение |
|------|---------|
| **Оплата западных API невозможна** | DeepSeek, Kimi, GLM, Mistral — китайские и европейские модели с прямой оплатой из РФ |
| **Риск бана аккаунта** | Никакой привязки к Anthropic/OpenAI — нельзя забанить то, чем ты не пользуешься |
| **Цена западных API** | В 5-18 раз дешевле с DeepSeek и китайскими провайдерами |
| **Платёжные ограничения** | Бесплатно и open source. Можно запустить вообще без API — локальные модели через Ollama/GigaChat/YandexGPT |
| **Английский интерфейс** | Русские промпты, русские инструкции, русский TUI |
| **152-ФЗ и РКН** | Встроенный справочник IT-права РФ (скилл `russian-it-law`). Данные на сервере в РФ |
| **Медленный старт** | Один скомпилированный бинарник, 227 MB, мгновенно |
| **Зоопарк инструментов** | 5 агентов + встроенные MCP-серверы (Constitution, Git, Puppeteer, SQLite) |

## Быстрый старт

NoCowboy пока не опубликован в npm. Сборка из исходников:

```bash
bun install --cwd packages/opencode build --single
cp packages/opencode/dist/nocowboy-tui-linux-x64/bin/nocowboy ~/.local/bin/nocowboy
```

Первый запуск:

```bash
nocowboy init          # мастер настройки (2 вопроса)
nocowboy mcp start     # запуск MCP-серверов
nocowboy               # старт TUI
```

Конфигурация: `~/.config/nocowboy/nocowboy.jsonc`

## Агенты

5 специализированных агентов:

| Агент | Роль | Модель |
|-------|------|--------|
| **code** | Пишет код | Flash (быстрая) |
| **architect** | Архитектура, планы, ADR, C4 | Pro (глубокая) |
| **debug** | Системная отладка | Flash |
| **overseer** | Ревью + оркестрация. Проверяет результат **другой моделью** | Kimi K2 / Pro |
| **nocowboy** | Автоматизация: браузер, файлы, система | Flash |
