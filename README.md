# NoCowboy

![NoCowboy](logo.svg)

**AI-агент для российских разработчиков.** Форк трёх MIT-проектов — [Kilo Code](https://github.com/Kilo-Org/kilocode), Xiaomi MiMo, Kibertum TAUSIK — перестроенный под рынок РФ. 12 месяцев работы одного разработчика. Ни одной зависимости от западных сервисов.

---

## Зачем

1.7 миллиона разработчиков в России. Все западные AI-инструменты — Claude Code, Cursor, Copilot, Codex, Aider — сделаны для англоязычного рынка. Они привязаны к OpenAI и Anthropic, требуют западные карты, не говорят по-русски и могут отключиться в любой момент.

Никто не делает инструмент для нас. Мы сделали.

## Почему не западные инструменты

### Их нельзя оплатить
Visa и Mastercard ушли из РФ. SWIFT-переводы заблокированы. Российские карты не принимает ни один западный AI-сервис. Оплата через посредников — +20-40% комиссии и риск бана без возврата.

### Их могут отключить
Аккаунт Claude, ChatGPT или Copilot может быть заблокирован при обнаружении российского IP или платёжного следа. Ты платишь $20-500 в месяц — а завтра остаёшься без доступа и без денег.

### Они говорят на английском
Все промпты, документация, интерфейс — на английском. Российский контекст (152-ФЗ, требования РКН, локальные стандарты) для них не существует.

### Они дорогие
Claude Sonnet 5: $2 вход + $10 выход за миллион токенов. Месяц разработки — $200-500. DeepSeek V4 Flash: $0.14 + $0.28 — **в 7-18 раз дешевле.** Но западные инструменты заточены под дорогие западные API.

## Что мы переделали

Мы не просто форкнули и перевели на русский. За 12 месяцев перестроена вся архитектура:

**15 агентов → 5.** Убрали мусор из апстрима (general, explore, scout, plan, orchestrator, ask, prd, ralph, researcher, code-reviewer). Оставили code, architect, debug, overseer, nocowboy — каждый с чёткой ролью.

**Свой MCP-фреймворк.** 8 серверов стартуют автоматически: Constitution (AST-проверка кода), Puppeteer (браузер), Git, SQLite, context7, и другие. Не надо запускать вручную.

**Русский язык.** Системные промпты, инструкции, TUI — всё на русском. Встроенный справочник IT-права РФ (152-ФЗ, РКН, локализация данных).

**Работает с доступными из РФ моделями.** DeepSeek, Kimi, Mistral, GLM — оплата напрямую, без посредников. Локальные модели через Ollama, GigaChat, YandexGPT — полностью офлайн.

**Скомпилирован в бинарник.** 227 MB, один файл. Node.js не нужен. Docker не нужен. Скопировал — работает.

**Память между сессиями.** FTS5 сохраняет найденные паттерны, баги и решения. При новом запуске агент помнит контекст предыдущей работы.

**Self-hosting.** NoCowboy разрабатывает сам себя. Все изменения в этом репозитории сделаны через NoCowboy. Никаких внешних зависимостей.

## Быстрый старт

```bash
bun install --cwd packages/opencode build --single
cp packages/opencode/dist/nocowboy-tui-linux-x64/bin/nocowboy ~/.local/bin/nocowboy

nocowboy init          # мастер настройки
nocowboy mcp start     # MCP-серверы
nocowboy               # старт TUI
```

Конфиг: `~/.config/nocowboy/nocowboy.jsonc`
