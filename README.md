# NoCowboy

![NoCowboy](logo.svg)

**AI-агент для российских разработчиков.** Единственный инструмент, созданный специально для рынка РФ — не форк, адаптированный под санкции, а продукт, изначально построенный для работы с китайскими и российскими моделями, на русском языке, с учётом 152-ФЗ и без единой зависимости от западных сервисов.

---

## Зачем

1.7 миллиона разработчиков в России. Все западные AI-инструменты — Claude Code, Cursor, Copilot, Codex, Aider — сделаны для англоязычного рынка. Они привязаны к OpenAI и Anthropic, требуют западные карты, не говорят по-русски и могут отключиться в любой момент.

Никто не делает инструмент для нас. Мы сделали.

NoCowboy — это не форк Kilo Code с парой фиксов под РФ. Это переосмысление того, каким должен быть AI-агент для российского разработчика: автономным, быстрым, русскоязычным и не зависящим ни от одного западного сервиса.

## Почему не западные инструменты

### Их нельзя оплатить
Visa и Mastercard ушли из РФ. SWIFT-переводы заблокированы. Российские карты не принимает ни один западный AI-сервис. Оплата через посредников — +20-40% комиссии и риск бана без возврата.

### Их могут отключить
Аккаунт Claude, ChatGPT или Copilot может быть заблокирован при обнаружении российского IP или платёжного следа. Ты платишь $20-500 в месяц — а завтра остаёшься без доступа и без денег.

### Они говорят на английском
Все промпты, документация, интерфейс — на английском. Агенты «думают» на английском. Российский контекст (152-ФЗ, требования РКН, локальные стандарты) для них не существует.

### Они дорогие
Claude Sonnet 5: $2 вход + $10 выход за миллион токенов. Месяц разработки — $200-500. DeepSeek V4 Flash: $0.14 + $0.28 — **в 7-18 раз дешевле.** Но западные инструменты заточены под дорогие западные API.

## Что даёт NoCowboy

**Автономность.** Один скомпилированный бинарник, 227 MB. Скопировал — работает. Node.js не нужен. Docker не нужен. Интернет не нужен — локальные модели через Ollama, GigaChat, YandexGPT работают полностью офлайн.

**Русский язык.** Системные промпты, инструкции, TUI — всё на русском. Встроенный справочник IT-права РФ (152-ФЗ, РКН, cookie law, локализация данных).

**Работает с теми моделями, которые доступны из РФ.** DeepSeek, Kimi, Mistral, GLM — оплата напрямую, без посредников. Никакой привязки к OpenAI/Anthropic.

**5 агентов, которые работают вместе.** code пишет, architect планирует, debug отлаживает, overseer ревьюит, nocowboy автоматизирует. Агенты делегируют друг другу задачи — как команда разработки.

**Память между сессиями.** FTS5 сохраняет найденные паттерны, баги и решения. При новом запуске агент помнит контекст предыдущей работы.

**Качество кода.** Constitution MCP проверяет код на уровне AST — никаких @ts-ignore, пустых catch, any. Pre-commit блокировка плохого кода.

**8 MCP-серверов из коробки.** Constitution, Puppeteer, Git, SQLite, context7 — стартуют автоматически, работают вместе.

**Self-hosting.** NoCowboy разрабатывает сам себя. Все изменения в этом репозитории сделаны через NoCowboy. Никаких внешних зависимостей.

## Быстрый старт

```bash
bun install --cwd packages/opencode build --single
cp packages/opencode/dist/nocowboy-tui-linux-x64/bin/nocowboy ~/.local/bin/nocowboy

nocowboy init          # мастер настройки
nocowboy mcp start     # MCP-серверы
nocowboy               # старт TUI
```

Конфиг: `~/.config/nocowboy/nocowboy.jsonc`
