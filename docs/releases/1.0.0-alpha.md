# NoCowboy 1.0.0-alpha — release notes

Первый релиз линейки 1.0. Для внутреннего использования (npm-публикация не выполнялась).

- **Версия:** `1.0.0-alpha`
- **Бинарник:** `packages/opencode/dist/nocowboy-linux-x64.tar.gz` (+ платформенные пакеты)
- **Установка:** `bun run release` → обновляет `~/.nocowboy/bin/nocowboy`
- **Проверка:** `~/.nocowboy/bin/nocowboy --version` → `1.0.0-alpha`

## Главное в релизе

### Разрешения и YOLO
- Глобальный YOLO-режим хранится в конфиге и читается лениво на каждом запросе, поэтому
  действует во всех инстансах и переживает перезапуск; явные запреты и защита конфигов
  по-прежнему выигрывают ( `5e8752ba04` ).
- Кнопка `[YOLO]` читает состояние из конфига и показывает ошибки тостом, а не молчит.

### TUI
- Кнопки мыши в промпте: `[Attach]` (пикер файлов: картинка/PDF/текст), `[Paste]`
  (буфер обмена), `[YOLO]`.
- Локализация завершена: переключатель языка в Settings (RU/EN), словарь ключей,
  таблица фраз для заголовков палитры и описаний привязок; переводятся промпт
  разрешений, футер, диалоги, системные экраны, подписи сайдбара.
- Удалена забытая отладка (запись в `/tmp/nocowboy-sidebar.log` на каждый маунт) —
  заменена штатным Log-сервисом.

### Экономика и надёжность
- **Бюджет сессии**: `budget` в конфиге (стоимость/токены, порог предупреждения,
  `abort` или `downgrade_model`), проверяется раз за ход по накопленным данным сессии.
- **Кросс-модельное ревью**: `review.cascade` — ревьюер выбирается по семейству
  модели-автора, вторая фаза ревью; по умолчанию выключено.
- **Durable workflows**: `nutausik_task_progress` (NUTAUSIK 0.3.1) + команда `/resume`;
  цель сессии persistится в `<data>/goals/<sessionID>.json` и продолжается после
  рестарта на следующем сообщении (авто-продолжение без сообщения намеренно выключено).
- **NUTAUSIK**: один MCP-сервер на все инстансы, проект передаётся с каждым вызовом
  (`projectDir`) — задачи и память больше не попадают в чужой проект.

### Инфраструктура и проверки
- Верификация роадмапа починена: посторонний пустой `docs/roadmap.json` в пакете
  молча отключал проверку; CLI делегирует репо-скриптам, хук использует их же.
  **147/147 фич, 236/236 директив.**
- Typecheck стал настоящим гейтом: pre-commit выполняет
  `bun turbo typecheck --force` и **блокирует** коммит при ошибке (раньше шаг был
  не-фатальным, а инкрементальный кэш мог скрывать ошибки). Тесты
  `nocowboy-indexing` включены в проверку типов — 66 ранее непроверенных ошибок
  найдено и исправлено.
- Ратчет качества: пустой `catch` обязан объяснить себя, `as-any` не растёт —
  блокирующий шаг в pre-commit.
- Headless-тесты TUI: pty-драйвер отвечает на запросы терминала, набор TUI **119/0**.
- Полный набор: **506 файлов / 506 passed / 0 failed / 0 flaky**.
- Workspace typecheck: **8/8**.

## Известные ограничения
- npm-публикация не выполнялась (нужен `npm login`); команда:
  `npm publish --access public --tag alpha`.
- Пуш и тег — за владельцем.
- `[Spec]`-задачи по двум запланированным фичам (`deep-context-2m`,
