# NoCowboy 1.0.6-alpha — release notes

Автопилот больше не путается с roadmap: **режим** и **цель** разведены. Кнопка
`[AUTOPILOT]` стала безопасным тумблером режима, появилась честно названная
цель `[FINISH ROADMAP ▶]`, а повторный запуск прогона больше не сбрасывает
прогресс. Для внутреннего использования (npm-публикация не выполнялась).

- **Версия:** `1.0.6-alpha`
- **Бинарник:** `packages/opencode/dist/nocowboy-linux-x64.tar.gz` (+ платформенные пакеты)
- **Установка:** `bun run release` → обновляет `~/.nocowboy/bin/nocowboy`
- **Проверка:** `~/.nocowboy/bin/nocowboy --version` → `1.0.6-alpha`

## Что изменилось

### Autopilot — это режим, roadmap — это цель

Раньше `/autopilot` без аргумента **и был** «сделай весь roadmap», поэтому
кнопка с именем «автопилот» на самом деле запускала цель. Теперь это две
ортогональные вещи:

- `/roadmap [--max-turns N]` — **цель** «добить `docs/roadmap.json`»:
  безлимитная, завершается детерминированно по roadmap.
- `/autopilot [scope] [--max-turns N]` — **режим**. Без аргумента армит **уже
  активную** цель; со scope ставит новую кастомную judged/bounded цель.
  Подкоманды: `status`, `off`/`pause`, `toggle`, `on`/`arm`, `resume`,
  `clear`/`stop`.

### Повторный запуск больше не сбрасывает прогон

`handleAutopilotCommand("")` звал `GoalService.set`, что обнуляло
`condition`/бюджет/`react`. Случайный клик (кнопка «Parent» в футере сабагента
стоит там же, где бейдж) перезапускал прогон с первого хода. Теперь:

- arm использует новый `GoalService.setAuto` — меняет только режим, цель и
  прогресс не трогает;
- `off`/`pause` ставит на паузу, **сохраняя цель**; клик по бейджу больше не
  разрушителен;
- `/roadmap` **идемпотентен**: running → «already active», paused → ре-арм,
  сброс только через явный `--max-turns N`.

### Интерфейс: одна кнопка запуска roadmap

- `[FINISH ROADMAP ▶]` в нижней панели **главного экрана** — один клик из нового
  чата; пункт палитры **Finish the roadmap (unattended)** и `/roadmap` — из
  существующего чата.
- `[AUTOPILOT]` / `[AUTOPILOT ON]` в сессии — только режим. Включён = продолжает
  без человека; выключен = пауза (цель цела).
- Сайдбарная кнопка roadmap **удалена**: она дублировала нижнюю и налезала на
  заголовок сессии.
- Бейдж игнорирует клики 250 мс после смены роута — навигационный mouse-up
  кнопки «Parent» больше не переключает режим.

### Headless

- `nocowboy run --autopilot` без сообщения → `/roadmap` (весь roadmap).
- `nocowboy run --autopilot "<scope>"` → `/autopilot <scope>` (как было).
- Восстановлен `process.exit(1)` для `--interactive` + `--autopilot`/`--roadmap`
  (был потерян в процессе правок; пойман локальным ревью).

## Известные ограничения

- npm-публикация не выполнялась (нужен `npm login`); команда:
  `npm publish --access public --tag alpha`.
- Пуш и тег — за владельцем.
- `blocked`/`abandoned` завершает прогон roadmap, но требует человека, чтобы
  разблокировать или оживить пункт.
- В существующем чате у roadmap-запуска нет видимой кнопки — только палитра
  (`Ctrl+P`) и `/roadmap`. Это осознанный выбор: один визуальный контрол вместо
  дублей.
