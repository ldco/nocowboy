# NoCowboy 1.0.8-alpha — release notes

Bugfix-релиз: агент `reviewer` больше не получает планировочный boilerplate.
Для внутреннего использования (npm-публикация не выполнялась).

- **Версия:** `1.0.8-alpha`
- **Бинарник:** `packages/opencode/dist/nocowboy-linux-x64.tar.gz` (+ платформенные пакеты)
- **Установка:** `bun run release` → обновляет `~/.nocowboy/bin/nocowboy`
- **Проверка:** `~/.nocowboy/bin/nocowboy --version` → `1.0.8-alpha`

## Что изменилось

### Проблема

В review-режиме агент `reviewer` получал `<system-reminder>` с заголовком
`## Plan File` и инструкциями «пиши план, вызови `plan_exit`» — чистый
планировочный boilerplate. Ревьюер не планирует, он верифицирует результат
worker; лишний boilerplate путал модель и подталкивал к неправильным действиям.

### Причина

Две ошибки классификации:

1. **`planning()` включала reviewer.** В `nocowboy/session/prompt.ts`
   предикат `planning()` возвращал `true` для `architect`, `planner` **и
   `reviewer`**, поэтому `insertPlanReminders()` вставлял plan-file boilerplate
   в промпт любого из них.
2. **reviewer имел планировочные permissions.** В `nocowboy/agent/index.ts`
   у reviewer стояли `plan_enter: "allow"` и `plan_exit: "allow"` —
   инструменты стадии планирования, а не верификации.

### Исправление

- `planning()` теперь возвращает `true` только для `architect`/`planner`.
  Reviewer исключён из plan-like набора. Заодно убран мёртвый
  `const id = ...` (не использовался).
- У reviewer убраны `plan_enter` и `plan_exit` из permissions.
- Добавлен regression-тест «reviewer is NOT a planning agent» в
  `test/nocowboy/plan-exit-detection.test.ts`: для `agent: { name: "reviewer" }`
  в промпт не попадают строки `Plan File`, `plan_exit`, `main plan file`.

Разведены два набора, которые раньше смешивались:

- `modes = ["architect", "planner", "reviewer"]` — **read-only** агенты для
  merge permissions (`guardPermissions` / `hardPermissions`).
- `planning()` — **plan-like** агенты для plan-file boilerplate.

Reviewer входит в первый, но не во второй.
