# NoCowboy 1.0.5-alpha — release notes

Автопилот стал настоящим режимом: одна кнопка из нового чата, без диалога scope, и
прогон идёт **до конца roadmap**, а не до фиксированного числа ходов. Для
внутреннего использования (npm-публикация не выполнялась).

- **Версия:** `1.0.5-alpha`
- **Бинарник:** `packages/opencode/dist/nocowboy-linux-x64.tar.gz` (+ платформенные пакеты)
- **Установка:** `bun run release` → обновляет `~/.nocowboy/bin/nocowboy`
- **Проверка:** `~/.nocowboy/bin/nocowboy --version` → `1.0.5-alpha`

## Что изменилось

### Автопилот запускается из нового чата

Раньше кнопка `[AUTOPILOT]` требовала уже открытой сессии: на домашнем экране
она показывала «Open a session first». Теперь клик из нового чата создаёт
сессию с текущими агентом и моделью, переходит в неё и стартует прогон.

Нажатие больше не открывает диалог scope — это **одноклик-тумблер**: `ON`
запускает, `OFF` останавливает (`/autopilot clear`). Кастомный scope по-прежнему
доступен слэш-командой `/autopilot <scope>`.

### Прогон идёт до конца roadmap

Две причины, по которым прогон останавливался на границе стадии R01 → R02,
устранены:

- **Жёсткий бюджет 20 ходов** очищал цель ровно на стыке стадий. Дефолтный
  `/autopilot` теперь — **roadmap-цель** с безлимитным бюджетом
  (`UNBOUNDED_MAX_TURNS`, большое число, а не `0` — так старый бинарник читает
  файл цели без «уже исчерпано»). Явный `--max-turns N` остаётся ограничителем, а
  кастомный scope сохраняет прежнее поведение (судья + 20 ходов).
- **LLM-судья видел только транскрипт** и мог ложно решить «met», пока впереди
  ещё planned-пункты. Завершение roadmap-прогона теперь **детерминированное**:
  харнесс читает `docs/roadmap.json` и останавливается, только когда в roadmap
  есть фичи и ни одна не actionable. Терминальные статусы — `done`, `blocked`,
  `abandoned`. Судья пропускается, пока roadmap читается.

Stall-guard для roadmap-прогона считает по actionable-пунктам (прогресс по
roadmap), а кастомный judged-прогон — по `in_progress`, чтобы его собственный
бюджет, а не roadmap, решал, когда остановиться.

### Устойчивость (по итогам локального ревью)

- `abandoned` больше не делает roadmap вечно незавершаемым.
- `goal_set` сохраняет флаг `roadmap` и бюджет (как уже сохранял `auto`) и
  игнорирует `max_turns <= 0` — мидрановый сброс не деградирует прогон до
  bounded/judged.
- Сериализация транскрипта для судьи выполняется только когда судья нужен.
- Домашний `createSession` вынесен в общий хелпер для бейджа и палитры.

## Известные ограничения

- npm-публикация не выполнялась (нужен `npm login`); команда:
  `npm publish --access public --tag alpha`.
- Пуш и тег — за владельцем.
- Режим `blocked`/`abandoned` завершает прогон, но требует человека, чтобы
  разблокировать или оживить пункт.
- Auto-resume без входных данных при запуске приложения по-прежнему выключен
  (осознанная граница); headless `run --continue` закрывает unattended-сценарий.
