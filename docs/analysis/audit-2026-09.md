## Swallowed errors

29 empty `catch` blocks in `src`. Most are legitimate best-effort cleanups, but
the YOLO button was a real case (now fixed). The pattern to avoid:
`catch { /* silently fail */ }` behind a user-visible control. Any future control
must surface failure (toast/log).

## Gates (fixed second pass)

The pre-commit typecheck was **non-fatal** ("pre-existing plugin errors may
fail") and tsgo's incremental cache could skip files it had already checked.
Together that let real errors survive behind clean commits — the same class of
bug as the stray empty roadmap that disabled verification.

- the hook now runs `bun turbo typecheck --force` and **blocks** on failure
- `packages/nocowboy-indexing` includes its `test/**/*` in the typecheck (with
  `bun` types), so 66 previously unchecked type errors surfaced and were fixed
- `packages/nocowboy-telemetry` gained `typecheck`/`test` scripts

Coverage note: `packages/http-recorder` (gitignored, local-only) has no scripts,
and `packages/nocowboy` is an empty directory — neither is part of the gate.
