# 152-ФЗ Compliance Analysis

> **Дата:** 2026-07-06
> **Продукт:** NoCowboy — AI-assisted development tool (TUI + MCP framework)
> **Юрисдикция:** Российская Федерация
> **Правовая база:** Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных»

---

## 1. Executive Summary

**Вывод: NoCowboy НЕ является оператором персональных данных по смыслу ст. 3 152-ФЗ и НЕ обязан направлять уведомление в Роскомнадзор по ст. 22 152-ФЗ.**

NoCowboy — инструмент, аналогичный интегрированной среде разработки (IDE), текстовому редактору или системе управления базами данных. Пользователь самостоятельно определяет цели обработки, состав данных и совершаемые операции. Все данные хранятся локально на устройстве пользователя. Разработчик не имеет доступа к обрабатываемым данным.

## 3. Правовой анализ: ст. 3 152-ФЗ (определение оператора)

### 3.1. Текст нормы

> **Статья 3. Основные понятия, используемые в настоящем Федеральном законе**
>
> 1) персональные данные — любая информация, относящаяся к прямо или косвенно определенному или определяемому физическому лицу (субъекту персональных данных);
>
> ...
>
> 3) **оператор** — государственный орган, муниципальный орган, юридическое или физическое лицо, самостоятельно или совместно с другими лицами организующие и (или) осуществляющие обработку персональных данных, а также определяющие цели обработки персональных данных, состав персональных данных, подлежащих обработке, действия (операции), совершаемые с персональными данными.

### 3.2. Квалификация NoCowboy

Признаки оператора по ст. 3:

| Критерий | NoCowboy (разработчик) | Пользователь |
|----------|------------------------|-------------|
| Определяет цели обработки | ❌ Нет — NoCowboy не диктует пользователю, для каких целей использовать инструмент | ✅ Пользователь решает: писать код, исследовать архитектуру, рефакторить |
| Определяет состав ПД | ❌ Нет — пользователь решает, какие данные отправлять в промптах | ✅ Пользователь определяет, какую информацию раскрывать |
| Осуществляет действия с ПД | ❌ Нет — NoCowboy — инструмент, обработка происходит на стороне пользователя | ✅ Пользователь совершает действия через интерфейс инструмента |
| Организует обработку | ❌ Нет — NoCowboy предоставляет функциональность, не контролируя её использование | ✅ Пользователь выбирает, когда и как использовать инструмент |
| Имеет доступ к обрабатываемым данным | ❌ Нет — данные хранятся локально, не передаются разработчику | ✅ Пользователь имеет полный доступ к своим данным |

### 3.3. Правовая позиция

NoCowboy является **программным обеспечением (инструментом)**, а не оператором персональных данных. Аналогичная правовая позиция применяется к:

- **IDE (VS Code, IntelliJ IDEA, PyCharm):** разработчики IDE не уведомляют РКН о том, что пользователи обрабатывают код, содержащий ПД.
- **Текстовым редакторам (Microsoft Word, Google Docs):** разработчики не являются операторами документов пользователей.
- **Системам управления базами данных (PostgreSQL, MySQL):** разработчики СУБД не уведомляют РКН о каждой базе данных пользователей.
- **Браузерам (Chrome, Firefox):** разработчики браузеров не являются операторами данных, которые пользователи вводят на веб-сайтах.

**Ключевой принцип:** если программное обеспечение не инициирует сбор данных, не определяет цели их обработки и не имеет к ним доступа, его разработчик не является оператором ПД.

### 3.4. Дополнительное основание: личные и семейные нужды

Даже если бы NoCowboy признали оператором, обработка данных осуществляется **исключительно для личных нужд** (программирование, разработка ПО). Статья 22(2) предусматривает исключение из требования уведомления для случаев, когда обработка осуществляется физическим лицом для личных и семейных нужд, если это не нарушает права субъектов ПД.

## 4. Правовой анализ: ст. 22 152-ФЗ (уведомление РКН)

### 4.1. Текст нормы

> **Статья 22. Уведомление об обработке персональных данных**
>
> 1. Оператор до начала обработки персональных данных обязан уведомить уполномоченный орган по защите прав субъектов персональных данных (Роскомнадзор) о своем намерении осуществлять обработку персональных данных.
>
> 2. Оператор вправе осуществлять обработку персональных данных без уведомления уполномоченного органа по защите прав субъектов персональных данных:
>
> ...
>
> 8) если обработка персональных данных осуществляется без использования средств автоматизации;
>
> ...

### 4.2. Применение к NoCowboy

Уведомление РКН по ст. 22 **не требуется** по двум самостоятельным основаниям:

**Основание 1 (основное):** NoCowboy не является оператором (см. раздел 3). Обязанность уведомления распространяется только на операторов. Разработчик инструмента ≠ оператор данных пользователя.

**Основание 2 (субсидиарное):** Обработка осуществляется для личных нужд физического лица в рамках использования инструмента, что подпадает под исключение из ст. 22.

## 5. Правовой анализ: ст. 6 (условия обработки)

> **Статья 6. Условия обработки персональных данных**
>
> 1. Обработка персональных данных должна осуществляться с соблюдением принципов и правил, предусмотренных настоящим Федеральным законом. Обработка персональных данных допускается в следующих случаях:
>
> 1) обработка персональных данных осуществляется с согласия субъекта персональных данных на обработку его персональных данных;
>
> ...

**Реализация:** Согласие пользователя реализовано через consent диалог при первом запуске TUI (P3-B2). Пользователь информирован о:
- Какие данные хранятся (история сессий, память NUTAUSIK, конфигурация)
- Что данные не передаются третьим лицам
- Что данные можно удалить через `/forget`
- Согласие сохраняется в `consent_152fz` KV store

- Удаляет `.kilo/` — legacy директория

## 8. Данные AI-провайдеров

NoCowboy отправляет промпты пользователя к выбранному AI-провайдеру (OpenAI, Anthropic, OpenRouter и др.) **только по прямому указанию пользователя**. Пользователь:
1. Самостоятельно выбирает провайдера
2. Самостоятельно вводит API-ключ (хранится локально)
3. Может использовать локальные модели (Ollama) — данные не покидают устройство

Взаимоотношения с AI-провайдерами регулируются их собственными офертой и политикой обработки данных. NoCowboy выступает как технический посредник (аналогично браузеру).
