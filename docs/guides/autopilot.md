# Автопилот и roadmap — как пользоваться

Этот гайд — для пользователя. Коротко: **что нажимать**, **что писать** и **что
делать, если что-то пошло не так**.

## Два понятия, которые нельзя путать

- **Цель** — *что* надо сделать. Например: «доделать весь `docs/roadmap.json`»
  или «починить упавшие тесты».
- **Автопилот** — *как* это делать: бот продолжает сам, без твоего «продолжай».
  Это режим, а не отдельная задача.

Цель можно поставить без автопилота, а автопилот — включить для любой цели.

## Быстрый старт

### Доделать весь roadmap

1. Нажми **`[FINISH ROADMAP ▶]`** в нижней панели на главном экране (новый чат).
2. Бот сам создаст сессию, выберет агента `auto` и начнёт прогон: worker →
   reviewer-гейт → следующий пункт.

Если ты уже в существующем чате — там этой кнопки нет, но то же действие
доступно двумя способами:

- палитра команд: `Ctrl+P` → **Finish the roadmap (unattended)**;
- команда: `/roadmap`.

Прогон идёт **до конца roadmap** и завершается сам, когда не осталось ни одного
actionable-пункта (`done` / `blocked` / `abandoned` — терминальные статусы).
Бюджета ходов у roadmap-прогона нет.

### Своя задача под автопилотом

```text
/autopilot fix the failing auth tests
```

Это ставит цель «Autopilot run complete: fix the failing auth tests.» и включает
режим. Такая цель оценивается LLM-судьёй после каждого хода и ограничена
бюджетом (по умолчанию 20 ходов, можно задать `--max-turns N`).

Или сначала цель, потом режим:

```text
/goal all tests pass
/autopilot
```

## Индикатор прогона

Две поверхности: **бейдж-тумблер** в промпт-баре (рядом с `[YOLO]`) отвечает за
режим, **секция «Roadmap» в сайдбаре** — за шаги.

### Бейдж в промпт-баре

| Бейдж | Что значит | Клик |
|---|---|---|
| `[AUTOPILOT]` | цели нет | подсказка: поставь `/goal` или `/roadmap` |
| `[AUTOPILOT ▶]` | своя цель, режим включён | **пауза** — цель и прогресс сохраняются |
| `[AUTOPILOT ⏸]` | своя цель на паузе | продолжить |
| `[ROADMAP ▶]` | roadmap-прогон идёт | **пауза** |
| `[ROADMAP ⏸]` | roadmap-прогон на паузе | продолжить |

`▶` — автопилот включён, `⏸` — на паузе. Клик **никогда не удаляет** цель и не
перезапускает прогон с нуля.

### Секция «Roadmap» в сайдбаре

Пока идёт roadmap-прогон, сайдбар показывает:

```
Roadmap  84/146
▶ r16-purchase-clarity        (текущий пункт)
[ ] next-item                 (что ещё осталось)
[ ] another-item
… +N more
```

- заголовок — прогресс `done/total` по `docs/roadmap.json`;
- `▶` — пункт, который выполняется сейчас;
- ниже — оставшиеся actionable-пункты чек-листом; клик по заголовку
  сворачивает/разворачивает длинный список.

Секция появляется только для roadmap-прогона и не мешает списку «Todo» (это
рабочий список агента, а «Roadmap» — план проекта).

## Управление

| Хочу | Команда |
|---|---|
| Поставить на паузу (цель остаётся) | `/autopilot off` (или `/autopilot pause`) |
| Продолжить после паузы | `/autopilot` (или `/autopilot resume`) |
| Переключить режим | `/autopilot toggle` |
| Посмотреть статус | `/autopilot status`, `/roadmap status` |
| Совсем отменить | `/autopilot clear` / `/roadmap clear` |
| Задать бюджет ходов | `/roadmap --max-turns 50` |

Сбросить активный roadmap-прогон и начать заново можно только явно —
через `--max-turns N`. Обычный повторный `/roadmap` в running-прогоне просто
скажет «already active» и ничего не тронет.

## Headless (CI)

```bash
nocowboy run --autopilot                 # весь roadmap до конца (unbounded)
nocowboy run --autopilot "docs cleanup" --max-turns 20   # своя цель
nocowboy run --agent goal "docs cleanup" --max-turns 20  # алиас
```

`--interactive` несовместим с `--autopilot`.

## Почему в интерфейсе одна кнопка запуска roadmap

Раньше кнопка была и внизу, и в сайдбаре — дублировали друг друга, а сайдбарная
ещё и налезала на заголовок сессии. Осталась одна, в нижней панели на главном
экране, плюс пункт палитры и слэш-команда. Меньше кнопок — меньше путаницы.

## Если что-то не так

- **Бейдж показывает `⏸`, а прогон «не идёт»** — он на паузе; цель сохранена.
  Нажми бейдж ещё раз или `/autopilot resume`.
- **Бейдж показывает `▶`, а ходы не идут** — режим включён, но прогон мог
  упереться в stall-guard (пункт не меняется много ходов) или завершиться.
  Проверь `/roadmap status`; если цель жива — напиши «continue» или
  `/autopilot resume`, режим возобновится.
- **`/roadmap` пишет «already active»** — прогон уже идёт; это защита от
  сброса. Посмотреть прогресс: `/roadmap status`.
- **Прогон остановился на пункте** — скорее всего пункт `blocked`: нужен человек,
  чтобы разблокировать. Разблокируй и снова `/roadmap`.
