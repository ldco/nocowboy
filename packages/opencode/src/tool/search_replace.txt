Edit files using Aider-style SEARCH/REPLACE blocks. Each block specifies a file path, the exact code to find (SEARCH), and the replacement code (REPLACE).

Format:
```
path/to/file.ts
<<<<<<< SEARCH
exact code to find
=======
new code to replace with
>>>>>>> REPLACE
```

Rules:
- Each block MUST have a file path on its own line, followed by SEARCH/REPLACE delimiters
- The SEARCH section must match the existing code exactly (including whitespace and indentation)
- The SEARCH section must match exactly ONE location. If it matches none, or more than one (including overlapping matches), the block fails and nothing is written — add surrounding context so the match is unique
- Multiple blocks can be used in a single call. Blocks for the same file are applied in order, each against the result of the previous one, and the file is written once
- If any block fails, no file is written (no partial edit)

Example - renaming a function:
```
src/greeter.ts
<<<<<<< SEARCH
function greet(name: string) {
  return `Hello, ${name}!`
}
=======
function greetUser(name: string) {
  return `Hello, ${name}!`
}
>>>>>>> REPLACE
```
