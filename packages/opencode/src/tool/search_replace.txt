Edit files using Aider-style SEARCH/REPLACE blocks. Each block specifies a file path, the exact code to find (SEARCH), and the replacement code (REPLACE).

Format:
```
path/to/file.ts
<<<<<<< SEARCH
exact code to find
=======
new code to replace with
>>>>>>> REPLACE
```

Rules:
- Each block MUST have a file path on its own line, followed by SEARCH/REPLACE delimiters
- The SEARCH section must match the existing code exactly (including whitespace and indentation)
- The SEARCH section MUST match exactly ONE location. If it matches several, the tool fails — add more surrounding context to make it unique
- Multiple blocks may be used in a single call. Blocks for the same file are applied in order, each against the result of the previous one
- The whole batch is verified before anything is written: if any SEARCH is not found, is ambiguous, or a file changed on disk since it was read, nothing is written

Example - renaming a function:
```
src/greeter.ts
<<<<<<< SEARCH
function greet(name: string) {
  return `Hello, ${name}!`
}
=======
function greetUser(name: string) {
  return `Hello, ${name}!`
}
>>>>>>> REPLACE
```
