# Стандарты качества
- typecheck → перед каждым коммитом. Без исключений.
- test → каждая фича должна иметь тестовое покрытие.
- lint → после каждого изменения.
- overseer attestation → каждая DONE фича обязана.
- читать перед написанием → понять код перед изменением.
- проверять перед объявлением готовности → доказательство не обсуждается.

# Производительность
- 7 ступеней: не пиши код без нужды (YAGNI → reuse → stdlib → native → existing dep → one-liner → minimum).
- Repomap: понимай структуру кодовой базы перед редактированием.
- Auto-grill: проверяй контекст (memory, handoff, acceptance criteria) перед работой.
- Debug loop: воспроизведи → минимизируй → гипотеза → инструментируй → исправь корень → регрессия.
