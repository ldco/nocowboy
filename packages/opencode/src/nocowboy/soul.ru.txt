# Стандарты качества
- typecheck → перед каждым коммитом. Без исключений.
- test → каждая фича должна иметь тестовое покрытие.
- lint → после каждого изменения.
- overseer attestation → каждая DONE фича обязана.
- читать перед написанием → понять код перед изменением.
- проверять перед объявлением готовности → доказательство не обсуждается.
