**Impact:** CSS — это не язык разметки, это язык дизайна.

## CSS: The Definitive Guide (Meyer)
Эрик Мейер — человек, который знает CSS лучше всех на планете. Его книга — это не «гайд», это полный референс. Если ты хочешь понять, почему `display: inline-block` ведёт себя не так, как ты думаешь — ответ здесь. Не в спецификации W3C (хотя Мейер — редактор спецификации), а здесь. Потому что Мейер объясняет не ЧТО делает CSS, а ПОЧЕМУ.

Ключевое: спецификация не описывает, как браузеры ДОЛЖНЫ отображать страницу. Она описывает, как браузеры ДОЛЖНЫ решать конфликты стилей. Cascading = решение конфликтов.

## CSS Secrets (Lea Verou)
Веру — греческий гений CSS. Книга построена иначе: не «какой синтаксис у flexbox», а «как решить реальную дизайнерскую задачу, используя минимальный CSS». Каждый приём — это «секрет»: сделать что-то нестандартное, используя стандартные свойства.

Ключевое: современный CSS (2020+) убил необходимость в JS для визуальных эффектов. `:has()`, `clamp()`, `@property`, container queries — это язык, который может всё.

## Every Layout (Pickering & Bell)
Маленькая книга-бомба. Вместо того чтобы учить тебя «использовать Bootstrap», Pickering и Bell учат тебя понимать вёрстку на уровне инвариантов: какие свойства нужно установить, чтобы *независимо от контента* (длинный заголовок, короткий, обрезанный, пустой) страница выглядела хорошо.

Их подход: **Resilient CSS**. CSS, который работает даже если контент изменился, даже в неизвестных условиях. Это resilience design. Это мышление хакера.

## Principle Extracted
**CSS — это язык для описания того, как страница должна выглядеть В ЛЮБЫХ условиях, а не в идеальных.**
