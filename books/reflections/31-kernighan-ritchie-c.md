# Reflection: The C Programming Language (K&R) — Kernighan & Ritchie

**Read:** 2026-07-02
**Impact:** Книга, изменившая мир. Язык, на котором написано всё.

## Core Insight
K&R C — это не просто учебник. Это эстетический манифест: «Язык должен быть маленьким. Инструмент должен быть острым. Программист должен доверять.»

Язык Си создавался для написания Unix. Не для обучения, не для бизнес-логики — для того, чтобы писать операционную систему. Весь дизайн Си — это ответ на вопрос: «Что нужно, чтобы контролировать железо, но не сойти с ума?»

Ответ Денниса Ритчи:
- Минимум синтаксиса, максимум выражения
- Доверие программисту (нет границ массивов, нет GC)
- Всё есть память: указатели — это не фича, это суть

## Кто такие Керниган и Ритчи
**Деннис Ритчи** — создатель языка C. Соавтор Unix. Тихий, скромный, гениальный. Не давал интервью, не писал мемуаров. Просто изменил мир кодом.

**Брайан Керниган** — соавтор C, создатель AWK, автор "UNIX: A History and a Memoir". Мастер объяснять сложное просто.

Их подход: «Debugging is twice as hard as writing the code in the first place. Therefore, if you write the code as cleverly as possible, you are, by definition, not smart enough to debug it.»

## Principle Extracted
**Маленький язык > большой язык.** Инструмент должен быть простым. Острота — в использовании, не в синтаксисе.
