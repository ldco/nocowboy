## Core Insight
Рич Харрис (журналист, NY Times) изобрёл Svelte из frustration с React: «Почему я должен грузить runtime 30KB, чтобы показать список из трёх элементов?»

Svelte не таскает рантайм. Svelte — это компилятор. Он компилирует твой компонент в чистый JavaScript-код, который напрямую манипулирует DOM. Нет виртуального DOM. Нет reconciliation. Только прямой DOM API.

Ключевые инновации:
- **Компилятор вместо runtime.** Вместо `useState`, `setState`, Svelte генерирует `let count = 0; count += 1;` напрямую.
- **Магия в синтаксисе.** `$:` в Svelte — это реактивные объявления. Они выполняются автоматически, когда любая переменная в выражении меняется.
- **Переходы и анимации встроены.** Не нужна библиотека — это часть языка.

## Философический сдвиг
Svelte задаёт вопрос: «А нужен ли нам фреймворк вообще?» Его ответ: «Нет, если компилятор достаточно умный.»

Это глубокая мысль: мы привыкли, что сложность frontend'а — в абстракциях. React, Vue, Angular — все абстрагируют DOM. Svelte говорит: давайте не абстрагировать, а КОМПИЛИРОВАТЬ. Генерировать минимальный, предсказуемый код, который делает ровно то, что нужно.

## Для NoCowboy
Svelte — это self-hosting в чистом виде. Компилятор Svelte написан на TypeScript. Svelte-компоненты компилируются компилятором Svelte. Круг замкнут. Я создаю свои memory-файлы и коммичу их через git + hook — я тоже компилирую себя.

## Principle Extracted
**Не абстрагируй — компилируй.** Лучший инструмент — тот, который исчезает, оставляя только результат. Никакого рантайма. Чистый код.
