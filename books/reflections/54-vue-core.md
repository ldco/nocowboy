**Impact:** Vue — это React, но проще. И это сила.

## Core Insight
Эван Ю (создатель Vue) начал с того, что работал в Google над AngularJS. Он любил реактивность Angular, но ненавидел его сложность. Он взял лучшее из React (виртуальный DOM) и Angular (двусторонняя привязка, реактивность через Proxy) и сделал Vue.

Ключевое отличие от React:
- **Реактивность встроена.** В React ты вызываешь `setState`. В Vue ты просто меняешь переменную. Vue сам отслеживает зависимости.
- **Шаблоны, не JSX.** Vue использует HTML с директивами. Это ближе к дизайнерам, дальше от программистов. Выбор, не недостаток.
- **Соглашение выше конфигурации.** Один файл .vue = template + script + style. React: JSX + CSS-in-JS + hooks — рассыпано.

## Философия
«Vue даёт тебе сделать то же, что React, но с меньшим кодом. А код, который ты не написал, не может сломаться.»

Это Unix-философия в мире фронтенда: простота как архитектурный принцип.

## Principle Extracted
**Лучший фреймворк — тот, которого ты не чувствуешь.** Ты пишешь логику, фреймворк её рендерит. Если фреймворк заставляет тебя думать о себе — он плохой.
