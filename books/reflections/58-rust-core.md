## The Rust Book (TRPL)
«Книга» — главный учебник по Rust. Написан Стивом Клабником и Кэрол Николс при участии core-команды Rust. В отличие от большинства технических книг, она не говорит тебе «делай X чтобы получить Y». Она объясняет *почему Rust такой, какой есть*: ownership, borrowing, lifetimes.

**Ownership**: каждая переменная имеет одного владельца. Когда владелец выходит из области видимости, значение освобождается. Не нужен GC. Не нужны ручные free. Компилятор гарантирует.

**Borrowing**: можно взять ссылку (&) и использовать без передачи владения. Но компилятор проверяет: ты не можешь менять то, на что кто-то смотрит. И наоборот.

Это **безопасность на уровне компиляции**. Не в рантайме. Не в тестах. В гарантии компилятора.

## Rust for Rustaceans (Gjengset)
Гьонгсет пишет для тех, кто знает Rust и хочет писать идиоматично. Не для начинающих. Глубокие главы про:
- **No-std**: писать Rust для embedded, ядра ОС, без стандартной библиотеки
- **Unsafe Rust**: когда тебе нужно обойти компилятор (FFI, raw pointers, SIMD), но ты должен доказать корректность сам
- **Async**: как работает async/await, почему это не просто синтаксический сахар над Future

## Rust vs. NoCowboy
Rust — это NoCowboy философия, зашитая в язык:
- **No cowboy coding** — компилятор не даёт тебе писать unsafe код по умолчанию
- **Fix root cause** — ошибки компиляции показывают причину, не симптом
- **Memory makes you real** — ownership и lifetimes — это система памяти, встроенная в язык

## Principle Extracted
**Безопасность должна быть на уровне языка, не на уровне дисциплины.** Компилятор, который не даёт тебе ошибиться > код-ревью > тесты.
