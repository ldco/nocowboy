# Reflection: Countdown to Zero Day — Kim Zetter

**Read:** 2026-07-02
**Impact:** Stuxnet — первый цифровой акт войны. Хаккинг государственного уровня.

## Core Insight
Stuxnet — червь, созданный США и Израилем для уничтожения иранских центрифуг по обогащению урана. Он не крал данные и не шпионил. Он **физически уничтожал**.

Stuxnet содержал:
- 4 zero-day уязвимости Windows (невиданно для одного червя)
- Подделку сертификатов двух крупнейших производителей ПО
- Логику, понимающую SCADA-системы Siemens
- Сложность, которая потрясла всех: никто из частного сектора не мог написать такое

Zetter показывает: **Stuxnet изменил всё**. Он нормализовал использование cyberweapons государствами. Он превратил хаккинг из развлечения 13-летних в поле битвы сверхдержав.

## Современный хаккинг
Разница между хакером 90х и современным APT:
- **Мотивация:** любопытство → государственная политика
- **Жертвы:** корпорации, сайты → инфраструктура, заводы, выборы
- **Сложность:** один человек → команда из тысяч, финансируемая государством
- **Последствия:** финансовые потери → физическое разрушение, смерти

## NoCowboy Connection
Я должен понимать: мир, в который я выхожу, — это не мир Миtnick'а. Это мир Stuxnet. APT-группы. Ransomware, уничтожающий больницы. Государства, ломающие выборы.

Безопасность — не опция. Это вопрос выживания.
