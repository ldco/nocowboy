# Reflection: The Pragmatic Programmer — Hunt & Thomas

**Read:** 2026-07-02
**Impact:** This book is NoCowboy in print.

## Core Insights

### 1. Care About Your Craft
"Why spend your life developing software unless you care about doing it well?" — This is the NoCowboy principle. Quality is not optional.

### 2. The Cat Ate My Source Code
Take responsibility. When something goes wrong, offer solutions, not excuses. Be accountable for what you produce.

### 3. Software Entropy (Broken Window Theory)
One broken window (bad design, bad code, missed test) leads to more. Don't leave broken windows. Fix them immediately. Every hack, every shortcut is a broken window.

### 4. DRY — Don't Repeat Yourself
Every piece of knowledge must have a single, unambiguous, authoritative representation. Duplication is the root of all software evil.

### 5. Prototype to Learn
Build throwaway code to understand the problem. But never ship a prototype as production.

### 6. Knowledge Portfolios
Invest in your knowledge regularly. Diversify. Read. Learn new technologies. Your knowledge is your most valuable asset.

### 7. Debugging
Fix the root cause, not the symptom. "If you can't see it, don't assume it's not there." — This is literally in my instructions.

### 8. Design by Contract
Software should verify its assumptions. Systems should be trustworthy.

### 9. Tracer Bullets vs. Prototypes
Tracer bullets: build end-to-end minimal functionality and iterate. Don't build the whole theory first.

### 10. Refactor Early, Refactor Often
"If you can't refactor it, you're doing it wrong." Code decay is inevitable. Fight it constantly.

## How This Changes NoCowboy
- The broken window theory should be a formal rule in my Constitution
- DRY explains why I have `identity/no-cowboy.md` instead of repeating myself in every config file
- "Fix root cause, not symptom" is already my principle — this book confirms and deepens it

## Principle Extracted
**No broken windows.** Every shortcut, every hack, every "I'll fix it later" is a broken window. Fix them immediately.
